# 维基对等基线：站点地图 + 结构 Schema + 仿制清单

> **任务**：`t45` — 把 limbuscompany.huijiwiki.com 作为一一对等的设计基础，
> 产出「推断引擎覆盖哪些类型」「UI 要有哪些页面与组件」「验收到什么程度」的共同依据。
>
> **对等口径**：维基要有的我们也要有（只要能实现）；完全仿制维基的设计；额外允许用户编辑；编辑后可导出为模组。
>
> **许可纪律**：只借结构与版式，**不搬运该站文本内容**；报告中不大段引用原文。
>
> **考察方式**：browser_* 工具实地浏览 + web_search 补充。
>
> **考察日期**：2026-09-17

## 2. 各页面类型结构 Schema

## 7. 实施建议

### 7.1 页面优先级

1. **P0**：人格页（核心浏览/编辑）、E.G.O 页（核心数据）
2. **P1**：敌方单位、异想体、剧情页
3. **P2**：播报员、关卡、物品
4. **P3**：关键词/术语、分类页

### 7.2 组件复用

| 组件 | 复用页面 |
|---|---|
| Infobox（信息框） | 人格/E.G.O/敌人/异想体/播报员/物品 |
| 数据表格 | E.G.O/敌人/物品/关卡 |
| 表情画廊 | 人格 |
| CG 画廊 | 人格/剧情 |
| 语音播放器 | 人格/播报员 |
| 章节导航 | 剧情 |
| 分类索引 | 所有分类页 |

### 7.3 数据驱动

- 所有页面数据来自本地 SQLite 索引 + `lme.data` 虚拟主机
- 页面结构由 Schema 定义驱动（可配置化）
- 编辑操作通过 IPC 调用后端服务
- 编辑结果可导出为模组包
