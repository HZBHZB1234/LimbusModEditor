## 1. 页面整体骨架

### 1.1 栅格系统

基于 **Bootstrap 栅格**（`col-md-*` / `col-sm-*`），移动端有折叠逻辑。

```
┌──────────────────────────────────────────────────────────┐
│ #skinContainer（固定顶栏，z-index:97，高 50px）           │
│   左：汉堡按钮 | 灰机 logo | 推荐/建站/社区/文档/App/朱雀  │
│   中：搜索框（占满 flex:1）                                │
│   右：登录 | 注册                                          │
├──────────────────────────────────────────────────────────┤
│ .skin-subnav（子导航条，维基名称 + 分类标签栏）            │
│   左：站点头像 + 站名                                      │
│   中：机制▼ | 数据▼ | 剧情▼ | 战斗▼ | 养成▼ | 活动▼ | 其他▼ | 工具▼ | 编辑▼ │
│   右：编辑这个导航 | 废墟图书馆 | 脑叶公司 | 技能制作模板  │
├──────────────────────────────────────────────────────────┤
│ #wrapper > #wiki-outer-body > #wiki-body > main#content   │
│   .row                                                     │
│   ├── aside.col-md-2  ← TOC 目录（桌面端左侧 2 列）       │
│   └── article.col-md-10 ← 主内容区（桌面端 10 列）        │
├──────────────────────────────────────────────────────────┤
│ 页脚：用户交流 | 站点支持 | 关注灰机 | 备案信息            │
└──────────────────────────────────────────────────────────┘
```

### 1.2 顶栏（#skinContainer）

| 元素 | 形态 | 备注 |
|---|---|---|
| 汉堡按钮 | 图标按钮（`n-button`） | 移动端展开侧边导航 |
| 灰机 logo | SVG 图 + 链接 | 指向 huijiwiki.com |
| 导航链接 | 5 个按钮/链接 | 推荐（下拉）、建站、社区、文档、App、朱雀青龙 |
| 搜索框 | `n-select` 组件 | placeholder「在 xxx 维基搜索页面」，flex:1 占满中间 |
| 登录/注册 | 次要按钮 | 未登录态 |

### 1.3 子导航（.skin-subnav）

| 元素 | 形态 | 备注 |
|---|---|---|
| 站点头像 + 名 | 圆形头像 + 文字 | 左对齐 |
| 分类标签栏 | 9 个按钮，每个带下拉箭头 | 机制/数据/剧情/战斗/养成/活动/其他/工具/编辑 |
| 跨维基链接 | 4 个链接 | 废墟图书馆、脑叶公司、技能制作模板等 |

### 1.4 内容区栅格（Bootstrap）

| 区域 | class | 桌面端 | 移动端 |
|---|---|---|---|
| TOC 侧栏 | `col-md-2 hidden-sm hidden-xs` | 左侧 2 列 | 隐藏 |
| 主内容 | `col-md-10 col-sm-12` | 右侧 10 列 | 全屏 12 列 |

### 1.5 页脚

四组链接 + 备案信息：
- **用户交流**：机长QQ群、Wiki编辑QQ群、媒体读者QQ群、灰机Club
- **站点支持**：申请建站、文档中心、维基化概述、使用条款、编辑条款
- **关注灰机**：微博、知乎、Bilibili、微信公众号
- **法律**：灰机停机坪、维基家园计划、关于灰机wiki、使用条款和声明、编辑条款、商务合作、MediaWiki/ICP备案

## 2. 单个实体页（人格页为例）的信息层级

以 `/wiki/格里高尔` 为样本。

### 2.1 标题区（#firstHeading）

```
<h1>格里高尔</h1>
<div id="contentSub">
  <a>用户:LOR bot</a> 于1个月前 <a>修改了</a> 此页面。
</div>
```

- `h1` 页面标题
- 副标题区：最后编辑者 + 编辑差异链接 + 时间

### 2.2 信息框（Infobox）

**HTML 结构**：`<table class="infobox">`

```
┌─────────────────────────────────────┐
│ [logo 图] 格里高尔                   │ ← infobox-title（th colspan=2）
│         Gregor（小号字）             │
├─────────────────────────────────────┤
│ [立绘图片，带 Tab 切换]              │ ← 多皮肤 Tab（LCB罪人 / 厨师）
├─────────────────────────────────────┤
│ CV          │ Choi Han              │
│ 性别        │ 男                    │
│ 身高        │ 167cm                 │ ← th.infobox-label + td.infobox-data
│ 体重        │ 68KG                  │
│ 性格特质    │ 讨人厌，无法遏制的变形 │
│ 职业        │ 边狱公司巴士部门 13号  │
└─────────────────────────────────────┘
```

**字段清单**（人格页）：CV、性别、身高、体重、性格特质、职业

**多皮肤 Tab**：使用 Bootstrap Tab 组件（`nav nav-limbuscompany` + `tab-content`），同一实体可有多套立绘/信息。

### 2.3 分节标题顺序（TOC 结构）

```
1. 介绍
2. 相关角色
3. 标题语音
4. 相关人格剧情（点击此处跳转）
5. 相关考据
6. 立绘
```

- TOC 使用 `data-spy="affix"` 实现吸顶
- 每节用 `<h2>` + `mw-headline` id
- 可含子节 `<h3>`

### 2.4 表格与卡片形态

**表格**：`table.wikitable` — 带边框的标准 wiki 表格，用于 E.G.O 数据、升级材料等。

**卡片**（相关角色区）：
```
┌─────────────┐
│ [头像裁剪]   │ ← clip-path 六边形
│  角色名      │
└─────────────┘
```
- 使用 `clip-path: polygon(...)` 实现六边形头像
- 横向排列，hover 有缩放效果

### 2.5 图片与画廊

- **立绘画廊**：自定义 `standcontainer` 组件
  - 左半：缩略图网格（`grid-template-columns: repeat(auto-fill, 75px)`）
  - 右半：大图预览 + 名称 + 下载按钮
  - hover 缩放 + 边框高亮

### 2.6 行内引用与内链

- 内链：标准 `<a href="/wiki/...">` 黄色链接（`color:#ffff2a`）
- 引用：`<blockquote class="quote well quote-primary">` 左边框样式
- 考据列表：`<ul><li>` 带编号标记

### 2.7 分类标签（页底）

```html
<div id="catlinks">
  <a>分类</a>：<a>需要帮助</a>
</div>
```

## 3. 多级页面与导航

### 3.1 子页面命名法

使用 **斜杠命名**：`/wiki/世界观/边狱公司`

- 父页面：`世界观`
- 子页面：`世界观/边狱公司`
- 在父页面的 TOC/导航网格中列出所有子页面

### 3.2 面包屑

子页面顶部显示父链接：
```
世界观 / 边狱公司
```
- 父名是可点击链接
- 当前页为纯文本

### 3.3 分类页

结构：
```
分类:需要帮助
├── A
│   ├── 奥提斯
├── B
│   ├── 编写常用模板
│   ├── Project:编写规范
│   ├── 边狱公司
├── E
│   ├── E.G.O
...
```

- 按首字母分组（A/B/C...）
- 链接列表带分类小标题

### 3.4 导航网格（子页面间跳转）

在 `世界观/边狱公司` 底部有横向链接网格：

```
世界观/都市    世界观/郊区    世界观/大湖    世界观/废墟
世界观/世界之翼  世界观/其他公司  世界观/协会   世界观/事务所
世界观/废墟图书馆出场事务所  世界观/边狱公司出场事务所
世界观/其他作品出场事务所  世界观/帮派  世界观/五指

世界观/血魔  世界观/清道夫  世界观/非人知性体
```

- 每行 3-4 个链接
- 无分组标题，纯平铺链接

### 3.5 首页卡片网格

首页使用 **col-md-6** 两列布局：
- 左列：「最近更新」卡片（角色 CG + 名称链接）
- 右列：收音机交互组件（自定义 HTML/JS）
- 后续区块：异想体/饰品/状态效果/探索事件等链接网格（3 列）

## 4. 交互与性能观感

### 4.1 目录吸顶

- TOC 使用 `data-spy="affix"` + `affix-top` class
- 桌面端（≥992px）显示在左侧 2 列
- 移动端隐藏（`hidden-sm hidden-xs`）
- 滚动时固定在顶部

### 4.2 图片懒加载

- 使用 `decoding="async"` 属性
- `srcset` 提供 1x/1.5x/2x 响应式图片
- 缩略图与高清图分离（`huiji-thumb.huijistatic.com` vs `huiji-public.huijistatic.com`）

### 4.3 折叠区

- E.G.O 列表页使用可展开/收起的区块（按角色分组）
- 点击罪人图像展开该角色所有 E.G.O 数据

### 4.4 表格横向滚动

- 长表格（如 E.G.O 数据表）使用 `table-responsive table-wrapper` 容器
- 超出宽度时横向滚动

### 4.5 其他交互

| 交互 | 实现 |
|---|---|
| 多皮肤 Tab | Bootstrap Tab（`data-toggle="tab"`） |
| 立绘缩略图切换 | JS 点击切换大图 + 下载按钮 |
| 图片放大 | 点击预览图 → `target="_blank"` 打开原图 |
| 搜索框 | `n-select` 组件，带下拉建议 |

## 6. 取舍表：本工具维基化关联页应照搬 / 应改造 / 应放弃

> 前提事实：本工具是**离线桌面工具**（WebView2 宿主），数据来自**本地游戏资源**，
> 非在线维基。前端工程根固定 `src/LimbusModEditor.Web/`。

### 6.1 应照搬（直接复用版式与结构）

| 项目 | 理由 |
|---|---|
| **信息框（Infobox）结构** | 字段清单 + 标签/值两列布局非常适合展示实体属性；离线工具天然适配（数据来自本地，无需联网） |
| **多级页面斜杠命名** | `世界观/边狱公司` 式的层级命名法适合组织复杂的多级内容；可在 WebView2 中用前端路由模拟 |
| **TOC 吸顶目录** | 桌面工具同样需要长文导航；吸顶目录对键盘/鼠标用户都友好 |
| **面包屑导航** | 多级页面必备；离线工具中更显重要（无浏览器后退按钮） |
| **分节标题顺序** | 介绍→属性→相关→考据→画廊 的信息层级通用且清晰 |
| **Tab 切换（多皮肤）** | 游戏内同一角色有多套人格/E.G.O，Tab 切换是天然选择 |
| **分类标签（页底）** | 离线工具中可改为「标签」或「类型」筛选 |
| **缩略图网格 + 大图预览** | 立绘/图片画廊的标准形态，离线工具完全适用 |
| **响应式图片 srcset** | 离线工具中可改为本地路径的多分辨率适配 |

### 6.2 应改造（保留结构，替换内容/交互）

| 项目 | 原站形态 | 本工具改造方案 |
|---|---|---|
| **搜索框** | 全局 wiki 搜索（联网） | 改为本地资源搜索（按容器路径/对象名/标签） |
| **最近更新** | 动态 wiki 最近编辑 | 改为「最近打开的项目/资源」或移除 |
| **收音机交互** | 自定义 JS 收音机（动态内容） | 移除或替换为工具版本信息/快捷入口 |
| **用户交流/QQ群** | wiki 社区链接 | 替换为工具反馈渠道（GitHub Issues/邮箱） |
| **登录/注册** | wiki 账户系统 | 移除（离线工具无需账户） |
| **编辑按钮** | wiki 编辑入口 | 替换为工具的「编辑模式」切换 |
| **评论区** | 无（灰机wiki 无评论） | 无需添加 |
| **E.G.O 数据表格** | 全量静态表格 | 改为可排序/筛选的交互式表格（支持本地编辑） |
| **内链跳转** | wiki 页面间跳转 | 改为前端路由跳转 + 跨工作台精确跳转（`RelationDeepLink`） |
| **分类页字母索引** | 按首字母分组 | 改为按类型/标签筛选 + 搜索 |
| **导航网格** | 首页卡片网格 | 改为工具功能入口（资源/音频/文本/预设/设置） |
| **页脚备案信息** | 中文 wiki 法律要求 | 替换为工具关于/版本/许可信息 |

### 6.3 应放弃（不适合离线桌面工具）

| 项目 | 理由 |
|---|---|
| **灰机 wiki 全局导航** | 工具无需跨维基导航 |
| **朱雀青龙/App 下载** | 推广性链接，工具中无意义 |
| **人机协议弹窗** | wiki 法律要求，工具无需 |
| **14 天公告弹窗** | 动态公告，离线工具无内容 |
| **跨维基友链** | 废墟图书馆/脑叶公司链接，工具中无意义 |
| **RSS/Atom 订阅** | 工具无需内容订阅 |
| **全站搜索建议** | 联网功能，改为本地搜索 |
| **用户贡献/编辑历史** | wiki 协作功能，工具中为单人使用 |
| **语言切换（多语言 wiki）** | 工具可固定中文界面 |
| **页面浏览量/统计** | 无意义 |
| **社交分享按钮** | 桌面工具无需 |

## 7. 前端实现建议

### 7.1 布局框架

- **整体**：CSS Grid / Flexbox 实现顶栏 + 侧栏 + 主内容 + 页脚
- **信息框**：CSS Grid 两列（标签 + 值），支持 Tab 切换
- **TOC**：固定侧栏 + 吸顶（`position: sticky`）
- **卡片流**：CSS Grid `repeat(auto-fill, minmax(...))`

### 7.2 组件清单

| 组件 | 用途 |
|---|---|
| `TopBar` | 工具标题 + 搜索 + 设置按钮 |
| `Sidebar` | 多级导航（树形 + 面包屑） |
| `InfoBox` | 实体属性展示（字段 + 值 + Tab） |
| `SectionTOC` | 吸顶目录 |
| `ImageGallery` | 缩略图网格 + 大图预览 |
| `DataTable` | 可排序/筛选的表格 |
| `CardGrid` | 卡片流（预设/实体列表） |
| `Breadcrumb` | 多级页面导航路径 |
| `TagList` | 分类/标签展示 |

### 7.3 数据结构映射

| wiki 结构 | 前端数据 |
|---|---|
| `table.infobox` | `EntityInfo { id, name, nameEn, fields: [{label, value}], tabs: [{label, image}] }` |
| TOC (`ul.nav-list`) | `TOCItem { id, text, level, children? }` |
| 分节 (`h2.mw-headline`) | `Section { id, title, content }` |
| 分类 (`#catlinks`) | `string[]` (标签列表) |
| 子页面链接 | `SubPage { title, path, parent }` |
| 卡片流 | `Card { id, title, subtitle, image, tags, count }` |
